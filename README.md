# bathesis-lbo-exits-via-spac-vs-ipo
Replication code for the bachelor's thesis "SPAC vs. IPO als Exit-Kanal nach Leveraged Buyouts" (Frankfurt School, 2026). Compares changes in performance and capital structure from t-1 to t+3 in a sample of 162 PE-backed US firms exiting via De-SPAC or IPO in 2016-2022. Reproduces Table 4 (OLS, HC3, median regression) and Table A2 (PyCaret ML).
